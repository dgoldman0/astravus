## Cross-game interface pass

The follow-up pass reviewed the title, shared navigation, reading controls, Settings, History, People/familiar descriptions, save/load pages, chapter selection, spoiler dialog, afterword, end card, and credits. The story-stage/portrait logic and chapter-entry state reconstruction were also checked against the scene sequence above. There are no new offscreen speaking-character gaps in the implementation: the portrait fallback remains active unless that speaker is visible as an actor or depicted in the current action illustration.

Small concrete fixes from this pass:

- The title now says `Version 0.1-alpha`, avoiding `Alpha 0.1-alpha`.
- Save and Load share their current page. Entering Save from the Automatic page now selects manual page 1; the Automatic tab is disabled while saving. Previously those slots appeared active but Ren'Py refused the write without explanation.
- Load buttons require both a loadable slot and compatible book metadata. The earlier-draft marker remains available for incompatible saves.
- Save guidance now accurately says that automatic saves retain the latest scene starts and that automatic/quick slots are reused. It no longer suggests every scene start remains available indefinitely.
- History, Credits, the People list, and Chapters accept Page Up/Down. The reading guide explains this and the optional unread-skip setting. Mouse, touch, and ordinary arrow-key focus navigation remain available.
- The spoiler dialog's initial keyboard focus is explicitly **Go back**. Escape still cancels it without starting the chapter.

The fresh native regression passed **156/156 assertions**. In particular, opening Save from Load's Automatic page was tested through an actual menu replacement, requiring both `on "show"` and `on "replace"` handling. The run also verified that returning to the title stops the story's custom ambience channel.
