# Visual novel development

This is the working area for art experiments, discarded alternatives, editing
projects and inspection history. The [game project](../../visual-novel/README.md)
contains the selected runtime materials, current production contracts and build
tools. The [character gallery](../../visual-novel/art/character-keys/index.html)
contains the twenty selected reference sheets and their seventeen character notes.

Use subject and purpose for new working folders. Keep the selected character
reference in the game project; keep its experiments and edit history here.
Record dates inside a receipt when they identify a review, rather than creating
another dated catch-all folder. A successful experiment becomes selected art
only when its production manifest and applicable visual checks are updated.

The previously ignored candidate directory and graphics workspace remain local
under `archive/local/early-art` and `archive/local/graphics-workspace`. The older
design proof is preserved under `archive/local/design-proof`; its six already
broken reference links were repaired using the exact stashed originals.
[Recovery provenance](archive/recovered-proof.json) identifies those 31 files.
These archived proposals remain unselected. All required immutable inputs for
active production edits remain tracked files or Git blobs.

The organization inventory preserves the pre-move hashes; source history before
the move is also available in commit `b8e7918`. Current game exports belong in
`visual-novel/dist/` and `visual-novel/build/`, not in this development archive.
