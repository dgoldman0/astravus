## Dialogue Characteristics

Each dialogue file includes:
- **Context**: Scene setting and narrative placement
- **Participants**: Characters involved with communication notes
- **Dialogue**: Full text of the exchange
- **Themes**: Key thematic elements explored
- **Connections**: Links to related events and character bios
