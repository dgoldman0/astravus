# Audio sources

All four WAV files are original procedural synthesis made for this chapter with `scripts/make_audio.py`: a quiet sustained chord and plucked-note score, garden air, rain, and a short wooden sound. No external recordings, samples, or generated voices are used. Files are mono PCM, 24 kHz, 16-bit. The script uses deterministic seeds and requires NumPy; gameplay does not require NumPy.
